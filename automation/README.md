# Automação

Exemplos curtos, sem biblioteca externa e sem ligação com uma infraestrutura real. Cada script valida a entrada, explica o uso e devolve um código de saída.

| Linguagem | Onde | Uso |
|---|---|---|
| PowerShell 5.1+ | [powershell](powershell/README.md) | Resumo do sistema, disco e serviço no Windows |
| Python 3.9+ | [python](python/README.md) | Log e alcance TCP |
| Bash (GNU) | [bash](bash/README.md) | Saúde do host Linux e idade de backup |
| PHP 8 CLI | [php](php/README.md) | Contagem de níveis em um log |

Nenhum deles envia dado para fora, além do teste de conexão feito pelo `network-check.py` contra o host que você informar.
