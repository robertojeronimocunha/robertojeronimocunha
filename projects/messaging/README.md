# Mensageria

Pasta reservada para documentação pública de notificação e integração: e-mail, alerta e fila.

Não há, neste momento, um projeto sanitizado para publicar. Nenhum servidor, fila, domínio ou credencial é descrito.

Quando houver material, o texto deve seguir o mesmo roteiro dos outros projetos: problema, objetivo, arquitetura, tecnologias, implementação, segurança, resultado e melhorias. Destinatários e exemplos continuam em `example.com`.
